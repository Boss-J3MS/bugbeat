# BugBeat ML Service

FastAPI microservice powering BugBeat's code-complexity/defect-prediction ensemble (CodeBERT + Random Forest + Neural Network) and multi-language complexity scoring. Called by the BugBeat backend's `/complexity` route — see the main project repo at [github.com/Boss-J3MS/bugbeat](https://github.com/Boss-J3MS/bugbeat).
